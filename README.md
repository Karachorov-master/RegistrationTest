# Registration Test

Automated positive registration test for the OpenCart demo website.

## Technologies
- Java
- Selenium WebDriver
- TestNG
- Maven

## Test Scenario
The automated test:
1. Opens the OpenCart website.
2. Navigates to My Account > Register.
3. Fills in the required registration fields.
4. Accepts the Privacy Policy.
5. Submits the registration form.
6. Verifies that the account was successfully created.
